# Dynamo

Downloads for Dynamo, the Dynamic Island + tiny roommate for your Mac notch. Website and live test drive: **https://dyna-mo.space**

**Download:** grab `Dynamo.dmg` from the [latest release](https://github.com/Oluwanifemi77/dynamo-releases/releases/latest).

## Install
1. Open the .dmg and drag Dynamo into Applications.
2. Dynamo is not notarized yet, so tell macOS it is okay (one time):
   ```
   xattr -dr com.apple.quarantine /Applications/Dynamo.app
   ```
   Or open it once, then System Settings > Privacy & Security > Open Anyway.
3. Open Dynamo, pick your Mac type, hover the top of your screen.

Already installed? From 0.3.3 on, Dynamo updates itself: menu bar icon, then Update.

Works on macOS 11 Big Sur and later, Apple silicon and Intel. Not affiliated with Apple.
